# Operation Skeleton Key — baseline (before fixes)

Measured 2026-11-24 on the restructured monorepo, production builds,
local warm server (localhost). Re-run with the same commands after each fix
round and append a new section below.

## Gate timing (production preview, 1280x800 dpr1, `qa/gate-baseline.mjs`)

| Milestone | ms |
| --- | --- |
| Static boot shell replaced | 156–243 |
| App mounted behind veil | 1314–2088 |
| Veil fade starts | 4190–4919 |
| Prologue interactive | 4691–5400 |

Read: the scheduler opens ~1.3–2 s in, then the BootGate holds a randomised
3–5 s (`HOLD_MS`) before fading. ~2.5–3.5 s of the first-load wait is pure
hold, not loading.

## Prologue leg (dev server, `qa/prologue-baseline.mjs`)

| Milestone | ms |
| --- | --- |
| Prologue interactive | 1503–2174 |
| Fall complete (white sheet) | 5344–6193 |
| Reveal done | 5608–6466 |
| Scroll unlocked | 9051 |

Hold-to-first-scroll: **~7.5 s** of non-interactive watching (0.72 s hold +
3.0 s fall + 0.2 s white + 0.9 s reveal + 2.6 s temple pause).

## Lighthouse (mobile simulated throttling, `npx lighthouse` on preview)

| Metric | Value |
| --- | --- |
| Performance score | **0.66** |
| FCP | 0.8 s |
| LCP | 2.8 s |
| Total blocking time | **3,640 ms** |
| Speed index | 2.7 s |
| Interactive | **7.4 s** |

Lighthouse measures the boot screen; the visitor's real path adds the 3–5 s
hold and the ~7.5 s prologue leg on top.

## Structure facts

- Film scroll length: `document.scrollHeight` = 32 viewport heights (25,600 px
  at 800 px tall) for ~25 words of content.
- Font payload in build output: ~730 KB across 7 faces (Newsreader normal +
  italic latin/latin-ext, Playfair, Cormorant, Neucha, Noto Devanagari,
  Noto Bengali) — for four narration lines and two Indic words.
- `window.__cosmos` / `window.__palace` QA hooks are dev-only: production
  journeys cannot be driven by QA tooling. (Found while measuring.)

## Reproduce

```bash
npm run build
npm run preview &                        # :4173
node qa/gate-baseline.mjs                # gate (preview, production)
npm run dev &                            # :5188
node qa/prologue-baseline.mjs            # prologue leg (dev only)
npx -y lighthouse http://localhost:4173/ --only-categories=performance \
  --output=json --output-path=.qa/lighthouse-baseline.json --quiet \
  --chrome-flags="--headless=new --disable-gpu"
```
